# Journalism Academy

منصة تعليمية عربية لطلاب الصحافة والإعلام، مبنية بـ HTML وCSS وJavaScript. يمكن تشغيلها محليًا، أو ربطها بـ Supabase لتصبح بيانات الطلاب والدكاترة والمقررات والملفات والاختبارات والدرجات مشتركة عبر الإنترنت.

## تشغيل الموقع محليًا
1. فك ضغط ملف `journalism_academy.zip` كاملًا.
2. على Windows شغّل `start-local.bat` بالنقر عليه مرتين، ثم افتح `http://localhost:8000`.
3. أو افتح Terminal داخل المجلد واكتب `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## ربط الموقع بـ Supabase
1. أنشئ مشروعًا في https://supabase.com/dashboard.
2. افتح SQL Editor في لوحة Supabase، والصق محتوى `supabase-schema.sql` بالكامل، ثم اضغط Run. الملف ينشئ الجداول والصلاحيات وسلة ملفات PDF ويضيف المقررات الـ16 الأساسية.
3. من Project Settings ثم API انسخ Project URL ومفتاح Publishable (أو anon public key القديم).
4. افتح `supabase-config.js` واستبدل القيمتين التجريبيتين:
   - `url`: رابط المشروع.
   - `anonKey`: مفتاح Publishable أو anon العام.
5. ارفع كل ملفات المجلد إلى جذر مستودع GitHub، مع استبدال النسخة القديمة، ثم اعمل Commit changes.
6. من Supabase افتح Authentication ثم URL Configuration، واجعل Site URL رابط GitHub Pages الخاص بك، وأضف نفس الرابط ضمن Redirect URLs. فعّل Email provider واتبع إعدادات تأكيد البريد حسب ما تفضله.
7. افتح رابط GitHub Pages، وسجّل حساب طالب تجريبيًا. جرّب حسابًا آخر للدكتور بعد اعتماد دوره كما هو موضح أدناه.

## اعتماد حساب الدكتور (خطوة أمان مطلوبة)
اختيار «دكتور» في نموذج إنشاء الحساب لا يمنح صلاحية الدكتور تلقائيًا؛ الحساب ينشأ كطالب إلى أن تعتمد الإدارة هوية صاحبه. بعد أن ينشئ الدكتور حسابًا ويؤكد بريده، نفّذ في SQL Editor هذا الأمر مع استبدال البريد:

```sql
update public.profiles
set role = 'doctor'
where id = (select id from auth.users where email = 'lecturer@example.com');
```

بعدها يسجل الدكتور الخروج ثم الدخول من جديد، وستظهر له لوحة الدكاترة. لا تمنح صلاحية الدكتور إلا للحسابات التي تحققت من أصحابها.

## ما الذي يعمل في وضع Supabase؟
- تسجيل حساب وتسجيل دخول وخروج عبر Supabase Auth.
- ملفات شخصية ودور طالب/دكتور وفرقة دراسية.
- المقررات والدروس المشتركة بين المستخدمين.
- تسجيل الطالب في المقررات المختارة ومزامنتها بين أجهزته.
- رفع ملفات PDF إلى Storage خاص مع روابط تحميل مؤقتة.
- إنشاء كويزات موجهة لفرقة محددة أو لمقرر محدد.
- حفظ مفاتيح الإجابة منفصلة، وتصحيح الإجابات داخل قاعدة البيانات بعد التسليم.
- حفظ محاولات الطلاب ودرجاتهم، وعرض كل دكتور نتائج الكويزات التي أنشأها فقط.

## مفاتيح Supabase والأمان
- المفتاح المسموح داخل `supabase-config.js` هو Publishable key أو anon public key فقط؛ هذا المفتاح مصمم للاستخدام في المتصفح مع تفعيل RLS.
- ممنوع وضع `service_role` أو أي Secret key في ملفات HTML/JavaScript أو مستودع GitHub.
- ملف SQL يفعّل Row Level Security ويحدد صلاحيات القراءة والكتابة.
- إنشاء حساب دكتور يتطلب اعتمادًا من الإدارة؛ لا تعتمد على قيمة الدور المرسلة من المتصفح.

## ملاحظات
- إذا لم تضع بيانات مشروعك في `supabase-config.js`، سيعمل الموقع في وضعه التجريبي المحلي القديم.
- ملفات PDF التي كانت محفوظة في المتصفح قبل الربط لا تنتقل تلقائيًا إلى Supabase؛ يجب إعادة رفعها من لوحة الدكتور بعد اعتماد حسابه.
- إذا كانت خدمة تأكيد البريد مفعّلة، يجب على المستخدم تأكيد البريد قبل أول تسجيل دخول.
